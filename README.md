# Disclaimer

This project only works with a single client despite the fact that there is a database for store player data. Only one instance exists. Stocks and events are modified whenever any player presses the next turn button, so the approach to how stocks are tracked and/or updated would have to be changed to allow multiple players.

As a game, this project has not been rigorously tested for balance.

# What is this?

Horde Management is a simplified and fictionalized fantasy stock trading game where a dragon has hired you to manage and grow it's wealth. You can buy and sell stocks that increase and decrease in value each quarter due to randomized events and a random background drift. 

There are two tabs present in the user interface, one shows the stocks you own and their various values, while the other shows the past events which occured last quarter. Stocks can be freely bought and sold in the stock interface. Pressing the "Next Quarter" button will calculate new events and changes to stock prices and your income from dividends, then update the UI.

# How to run

to run this project, make sure that you have docker installed (type "docker version" to ensure it's installed). Navigate to the directory housing this project and type "docker compose up". This will build the poject and you can then navigate to any browser and go to "http://localhost:5173/" to see the user interface.

# How this project works

This project runs in docker and uses React, Flask, and Mongodb in 3 separate containers to accomplish it's function. All calculations are done on the backend in python, blocking the user from buying or selling when they have insufficient gold or stocks.

horde-management/frontend:
Generated by Vite; src contains the .tsx files.

horde-management/backend:
API.py contains the Flask server and basic information required for the program. Init.py provides functions to initialize the database, while turn_management.py advances the turn on the backend. The .json files in the backend are read into the database on startup and define the stocks available and the events that can appear.
